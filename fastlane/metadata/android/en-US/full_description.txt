<p><b>AppManagerNG</b> gives you a detailed view of the apps installed on your Android device, plus the tools to change them carefully. It works without root for everyday inspection and standard Android actions. Choose a privileged mode when you need deeper package control.</p>

<p><b>Find what Android normally hides</b></p>

<ul>
<li>Inspect activities, services, receivers, providers, permissions, AppOps, signatures, trackers, libraries, storage, usage, and manifests</li>
<li>Build reusable Finder queries for package state, sensitive access, installer, SDK level, size, backups, bloatware classification, and native-library readiness</li>
<li>Review Camera, Location, Contacts, Notifications, and other sensitive permission groups across every installed app</li>
<li>See evidence labels in tracker scans and useful explanations when Android blocks an action</li>
</ul>

<p><b>Maintain your device</b></p>

<ul>
<li>Install APK, APKS, APKM, XAPK, split APK, and OBB packages</li>
<li>Freeze, force-stop, clear, uninstall, archive, or back up supported apps</li>
<li>Use reviewed batch operations, scheduled profiles, package-event triggers, and Tasker-compatible intents</li>
<li>Work with the built-in debloater, file manager, code editor, log viewer, terminal, and shared-preferences editor</li>
</ul>

<p><b>Keep a way back</b></p>

<p>Backups can include APKs, app data, rules, permissions, roles, and extras where the selected access mode permits it. Encrypted snapshot bundles carry rules, profiles, and preferences between devices with a preview before restore.</p>

<p><b>Private by default</b></p>

<p>AppManagerNG has no ads, analytics, telemetry upload, or bundled tracking SDKs. The FLOSS build removes optional third-party report features at compile time. The full build makes VirusTotal reports and debloat-list updates available, but leaves them off until you enable them.</p>

<p>AppManagerNG is a maintained continuation of Muntashir Al-Islam's App Manager. Source code, signing fingerprints, reproducible-build notes, checksums, and release evidence are published with the project.</p>
